# Security Policy

## Supported versions

This repository currently maintains the latest version of the skill.

## Reporting a vulnerability

If you find a security issue, please avoid sharing exploit details publicly.

Open a private report through GitHub security reporting when available, or contact the repository maintainer through a private channel.

## Scope

This skill is primarily documentation and instructions. Security-sensitive changes may include:

- Instructions that cause agents to run untrusted code.
- Instructions that encourage leaking private data.
- Examples that include secrets, tokens, credentials, or internal URLs.
- Scripts or automation added in future versions.
