# Changelog

## v0.1.0 - 2026-06-16

Initial release of Open Knowledge Format Skill.

### Added

- `SKILL.md` with `open-knowledge-format` skill metadata and OKF execution workflow.
- English README with `npx skills add hu-qi/OpenKnowledgeFormat-Skill` installation command.
- Chinese README at `README.zh-CN.md`.
- OKF concept template at `templates/concept.md`.
- Minimal software project OKF example under `examples/software-project-okf/`.
- GitHub community files, including contribution guide, code of conduct, security policy, issue templates, and pull request template.

### Notes

This release targets OKF bundle creation, conversion, validation, index generation, log generation, and agent-readable knowledge catalog design.
