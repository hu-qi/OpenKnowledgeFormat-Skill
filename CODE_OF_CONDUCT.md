# Code of Conduct

This project follows a simple standard of respectful collaboration.

## Expected behavior

- Be kind and constructive.
- Focus feedback on the work, not the person.
- Welcome different experience levels.
- Assume good intent while being clear about problems.

## Unacceptable behavior

- Harassment or personal attacks.
- Discriminatory language.
- Repeated off-topic disruption.
- Publishing private information without permission.

## Reporting

If you see behavior that does not match this code of conduct, open a private channel with the repository maintainer when possible.
