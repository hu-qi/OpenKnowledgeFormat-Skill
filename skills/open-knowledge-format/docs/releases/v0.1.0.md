# Open Knowledge Format Skill v0.1.0

Initial release of Open Knowledge Format Skill.

## Highlights

- Adds `SKILL.md` for creating, converting, validating, and maintaining OKF knowledge bundles.
- Adds English and Chinese README documentation.
- Adds `npx skills add hu-qi/OpenKnowledgeFormat-Skill` installation instructions.
- Adds reusable OKF concept template.
- Adds a minimal software project OKF example bundle.
- Adds GitHub community files and issue/PR templates.

## Installation

```bash
npx skills add hu-qi/OpenKnowledgeFormat-Skill
```

Manual fallback:

```text
.codex/skills/open-knowledge-format/SKILL.md
```

## Scope

This release focuses on:

- OKF bundle creation.
- Existing material conversion to OKF.
- OKF v0.1 validation.
- `index.md` generation.
- `log.md` generation.
- Agent-readable knowledge catalog design.

## Notes

This is the first public release. The skill keeps the main `SKILL.md` concise and places reusable long-form material in `templates/` and `examples/`.
