# Overview

A User Session represents the authenticated state of a user.

# Details

A session usually starts after successful login and ends when the user logs out, the session expires, or the token is revoked.

# Relationships

- Created by [Login API](/apis/login_api.md).
- Consumed by [Frontend App](/systems/frontend_app.md).
