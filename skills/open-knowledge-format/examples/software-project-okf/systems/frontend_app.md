# Overview

The Frontend App is the primary user-facing web application.

# Details

It renders pages, calls backend APIs, handles client-side routing, and provides the interaction layer for users.

# Relationships

- Uses [Login API](/apis/login_api.md) for authentication.
- Creates and consumes [User Session](/concepts/user_session.md) state.
- Released through [Deploy Frontend](/runbooks/deploy_frontend.md).
